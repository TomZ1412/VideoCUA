# Metadata examples

These synthetic examples document the JSON structures consumed or produced by the released code.
They do not contain benchmark annotations, generated guidance, or model outputs from the paper.

The three `*_task_to_video.json` files in [`metadata/`](../metadata/) are the only released
task-level metadata. Each maps a task ID to one or more video IDs in the corresponding Hugging Face
dataset. Descriptions and guidance must be generated by the user.

`vss_task_to_guidance_example.json` documents the task-keyed textual guidance consumed by the
video-SALMONN-VEX runners. `gemini_video_to_description_example.json` documents the video-keyed
description mapping consumed by the Gemini OSWorld runner.
